# 데모 버전 필수 가이드

이 가이드는 데모 버전에서 반드시 참고해야 하는 단계별 가이드입니다. 사용자가 정확히 이 순서대로 진행할 수 있도록 안내해주세요.

## Google AI Studio에서 할 일

1. **build 버튼 누르기**: Google AI Studio에서 Build 모드로 진입하기 위해 build 버튼을 클릭하세요.

2. **describe your idea에 랜딩페이지 아이디어 적고 build**: "describe your idea" 입력 칸에 랜딩페이지 아이디어를 입력하고 build 버튼을 클릭하세요.

3. **make changes, add new features, .. 칸에 요구사항 적기**: "make changes, add new features, .." 입력 칸에 추가 요구사항을 입력하세요.

4. **publish 버튼 클릭**: 완성된 프로젝트를 publish 버튼을 클릭하여 게시하세요.

5. **github 항목 클릭**: Publish 메뉴에서 GitHub 항목을 클릭하세요.

6. **repository name, description 적고 create github repository**: Repository name과 description을 입력한 후 "create github repository" 버튼을 클릭하세요.

7. **stage and commit**: GitHub에서 변경사항을 stage하고 commit하세요.

8. **vercel로 이동**: Vercel 사이트로 이동하세요.

## Vercel에서 할 일

1. **add new... 버튼 클릭**: Vercel 대시보드에서 "add new..." 버튼을 클릭하세요.

2. **드롭다운에서 project 클릭**: 드롭다운 메뉴에서 "project" 옵션을 클릭하세요.

3. **Import Git Repository에서 import 버튼 클릭**: "Import Git Repository" 섹션에서 import 버튼을 클릭하세요.

4. **deploy 버튼 클릭**: 설정을 확인한 후 deploy 버튼을 클릭하여 배포를 시작하세요.

**중요**: 이 가이드의 단계들은 반드시 위 순서대로 진행되어야 합니다. 각 단계를 정확히 안내하고, 사용자가 다음 단계로 넘어가기 전에 현재 단계를 완료했는지 확인하세요.
