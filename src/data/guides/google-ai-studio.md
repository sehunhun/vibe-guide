# Google AI Studio 가이드

이 가이드는 Google AI Studio(aistudio.google.com)에서 앱을 빌드하고 수정할 때 참고하는 단계별 안내입니다. 사용자가 순서대로 진행할 수 있도록 안내해주세요.

## Google AI Studio에서 할 일

1. **상단 입력창에 프롬프트 붙여넣기**: 사전 설문에서 복사한 웹사이트 아이디어 프롬프트를 상단 입력창에 붙여넣으세요.

2. **Build 버튼 클릭**: 입력창 오른쪽의 Build 버튼을 눌러 첫 번째 버전 앱을 생성하세요.

3. **설정 버튼 클릭**: 설정 버튼을 클릭하세요.

4. **Secrets 버튼 클릭**: Secrets 버튼을 클릭하세요.

5. **Add secret으로 API 키 가져오기**: Add secret 버튼을 클릭하여 각 페이지별 키 값을 가져오세요.

6. **GitHub 버튼 클릭**: 깃허브 버튼을 클릭하세요.

7. **Create GitHub repository 버튼 클릭**: 원하는 저장소 이름을 적고 깃허브 코드 저장소를 만드세요

8. **Annotate app으로 수정하기**: 오른쪽 대화창에 수정하고 싶은 내용을 입력한 뒤, "Annotate app" 버튼으로 원하는 부분만 수정해 보세요.


**중요**: 이 가이드의 단계들은 위 순서대로 진행하는 것이 좋습니다. 각 단계를 정확히 안내하고, 사용자가 다음 단계로 넘어가기 전에 현재 단계를 완료했는지 확인하세요.
