# Google AI Studio 가이드

이 가이드는 Google AI Studio(aistudio.google.com)에서 앱을 빌드하고 수정할 때 참고하는 단계별 안내입니다. 사용자가 순서대로 진행할 수 있도록 안내해주세요.

## Google AI Studio에서 할 일

1. **Build 버튼 클릭**: 사전 설문에서 복사한 웹사이트 아이디어 프롬프트를 입력하고 Build 버튼을 누르세요.

2. **설정 버튼 클릭**: 설정 버튼을 클릭하세요.

3. **Secrets 버튼 클릭**: Secrets 버튼을 클릭하세요.

4. **Add secret으로 API 키 가져오기**: Add secret 버튼을 클릭하여 각 페이지별 키 값을 가져오세요.

5. **GitHub 버튼 클릭**: 깃허브 버튼을 클릭하세요.

6. **Create GitHub repository 버튼 클릭**: 원하는 저장소 이름을 적고 깃허브 코드 저장소를 만드세요

7. **Annotate app으로 수정하기**: 오른쪽 대화창에 수정하고 싶은 내용을 입력한 뒤, "Annotate app" 버튼으로 원하는 부분만 수정해 보세요.


**중요**: 이 가이드의 단계들은 위 순서대로 진행하는 것이 좋습니다. 각 단계는 언급되지 않은 세부 단계로 나뉘어 질 수 있습니다.
